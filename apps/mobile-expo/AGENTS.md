# Spice Mobile (Expo) — agent notes

React Native rewrite of the native Android client in `apps/mobile`. It is a
standalone npm project (not part of the root workspace) with its own
`package-lock.json`. The root `AGENTS.md` policies apply here too.

## Expo changes every SDK

This app is on Expo SDK 57 / React Native 0.86 (New Architecture, Hermes).
Before touching an Expo or React Native API, check the versioned docs at
`https://docs.expo.dev/versions/v57.0.0/` rather than relying on memory, and add
packages with `npx expo install <package>` so versions match the SDK.

## Layout

- `App.tsx`, `index.ts`: entry; builds one `SpiceController` and the theme.
- `src/core/`: platform-free logic (models, parsers, sync merges, playback
  planning, Spice Connect, API client). Plain `.ts` with `.ts` import
  extensions so Node can run the tests directly. No React Native imports here.
- `src/data/`: persistence — `expo-sqlite` library, `kv-store` prefs,
  `expo-secure-store` credentials, downloads.
- `src/engine/`: typed facade over the native `SpiceEngine` module.
- `src/state/`: `SpiceController` (port of the Kotlin `SpiceViewModel`) and the
  `Store`/`useStoreSelector` state container.
- `src/ui/`: screens, sheets, player, primitives, and the UI v2 theme tokens.
  `icons.tsx` is generated from `apps/backend/app/ui-v2/icons.tsx`.
- `modules/spice-engine/`: local Expo module (Kotlin). Media3
  `MediaSessionService` playback with crossfade and background queue
  continuation, SoundCloud and NewPipe stream resolution, and track priority /
  background history stores. JVM tests live under `android/src/test`.
- `plugins/`: config plugins for native settings.
- `android/`, `ios/`: generated by `expo prebuild` (Continuous Native
  Generation). Never edit or commit them; change `app.config.ts` or a plugin.

## Commands

Run from `apps/mobile-expo`:

- `npm ci`: install dependencies.
- `npm run check`: typecheck, lint, and the Node tests for `src/core`.
- `npm run android:debug`: prebuild and assemble a debug APK
  (`arm64-v8a,x86_64`; override with `SPICE_ANDROID_ABIS`).
- `npm run android:release`: prebuild and assemble the release APK.
- `npm run android:engine:test`: the native engine's JVM unit tests.
- `npm start`: Metro dev server for the debug build.

On Windows, React Native's native builds create paths past 260 characters.
They need `LongPathsEnabled` and ninja 1.12+, so install SDK CMake 3.30 or
newer (`sdkmanager "cmake;3.31.6"`); `scripts/build-android.mjs` points
`android/local.properties` at the newest one it finds.

## Conventions

- Match the web UI v2 design: use `useTheme()` tokens and the primitives in
  `src/ui/primitives.tsx`; never hard-code theme colors. Theme changes in
  Settings must apply immediately.
- Keep behavior equivalent to `apps/mobile` unless a difference is intentional
  and documented. Background playback relies on direct HTTPS audio URLs.
- React compiler lint rules are on: avoid `setState` in effects and reading refs
  during render; key a child component to reset its state instead.
